# BSM Chat

Arabic multi-stream chat and activity dashboard for Twitch, Kick, and experimental TikTok LIVE.

See [README_AR.md](README_AR.md) for setup, provider configuration, test status, deployment costs, and limitations.

Node 24. `npm ci`, configure `.env`, then `npm start`. Test with `npm test`.

This is a self-hosted first implementation, not a verified live integration or a finished commercial SaaS. Twitch/Kick application credentials and provider authorization are required. TikTok uses an unofficial connector.
